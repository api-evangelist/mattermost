Mattermost v11.10 gives security admins tighter, faster control over who accesses what. ABAC governance now reaches team-level membership and native user attributes let admins write policies without any extra integration work. AI agents get more capable and reliable, too, with dynamic tool calling, on-demand file context, and automatic fallback if a model goes down.
